הפקודות להתקנת הספריות הנדרשות:
pip install Flask pywebview pypdf pdf2docx docx2pdf img2pdf Pillow pywin32 pyinstaller

להמרת וידאו ושמע (mp4, avi, mkv, mp3, wav, flac) צריך את ffmpeg.exe באותה תיקייה של קובץ התוכנה. בלעדיו תופיע ההודעה "קובץ ffmpeg.exe חסר". אפשר להוריד אותו מהאתר הרשמי ffmpeg.org.
